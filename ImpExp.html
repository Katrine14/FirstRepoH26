We have to get the read just right, else we will end up with a lot of pain.

En siste ting. « Registrert helt arbeidsledige» i nesten alle variabelnavnene er en plage. Vi kan få dem bort vha.

# str_replace_all er fra stringr pakken i tidyverse 
# som vi skal lære mer om senere
names(df)[-c(1:2)] <- str_replace_all(tail(names(df), n = -2), " Registrert helt arbeidsledige", "")
# gsub er fra base pakken. pattern er en såkalt regexp 
# og angir at «white space», «(», «)» og «-» skal byttes ut med ingenting.
# Vi kommer til å dekke litt elemtære regexp når vi studerer stringr
# som lm() er gsub() en funksjon som IKKE har data som første argument
names(df) <- gsub(
  pattern = "[\\S\\(\\)-]", 
  replacement = "",
  x = names(df)
  )
